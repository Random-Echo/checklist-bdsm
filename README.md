# Checklist BDSM

Application web statique pour aider deux adultes consentants a comparer leurs envies, limites, experiences et fantasmes autour d'une checklist BDSM.

Le principe est simple :

- chacun repond de son cote en mode **Edition** ;
- le mode **Lecture** croise les reponses du couple ;
- les pratiques compatibles, limites, fantasmes et experiences deja faites sont affichees clairement ;
- les donnees restent dans le navigateur, sans compte ni serveur.

## Acces
- Checklist : https://random-echo.github.io/checklist-bdsm/checklist.html

## Confidentialite

L'application utilise uniquement le stockage local du navigateur (`localStorage`).

Elle ne contient pas d'analytics, pas de compte utilisateur, pas d'email de contact et pas de synchronisation distante. Les sauvegardes/imports se font via fichiers JSON choisis par l'utilisateur.

Version publique actuelle : **V1.1**.
